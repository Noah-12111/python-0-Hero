## 🧭 Python Journey là gì?

**Python Journey** là một lộ trình học Python cơ bản kéo dài **15 tuần**, được thiết kế theo hướng:

```text
📖 Learn
   ↓
🛠️ Build
   ↓
🧪 Test
   ↓
🐛 Debug
   ↓
✨ Improve
   ↓
📦 Commit
   ↓
✅ Prove
```

Mục tiêu không phải là:

> ❌ "Học thuộc thật nhiều cú pháp Python."

Mà là:

> ✅ **Có thể tự viết một chương trình nhỏ, kiểm tra nó, debug nó và giải thích được vì sao nó hoạt động.**

# 🧠 Triết lý học

Python Journey **không** đi theo mô hình:

```text

      ↓

      ↓

      ↓
```

```text

  ↓
```

# 🚀 Đầu ra sau 15 tuần

Sau khi hoàn thành Python Journey, người học có thể:

* 🐍 Viết chương trình Python rõ ràng với biến, điều kiện, vòng lặp và hàm.
* 📦 Sử dụng `list`, `tuple`, `dict`, `set` phù hợp.
* 🔤 Xử lý chuỗi và biết khi nào regex hữu ích.
* 📁 Đọc/ghi file, CSV, JSON và sử dụng `pathlib`.
* 🐛 Đọc traceback và debug có phương pháp.
* 🧪 Viết test cơ bản bằng `pytest`.
* 🧩 Tổ chức code thành module.
* 🌐 Gọi HTTP API đơn giản và xử lý JSON.
* 🏷️ Hiểu type hints như một contract hỗ trợ người đọc và tooling.
* 🏗️ Sử dụng class khi OOP thực sự làm mô hình rõ hơn.
* 🌿 Sử dụng Git/GitHub để quản lý lịch sử phát triển.
* 🎓 Hoàn thành một capstone có code, tests, README và bằng chứng chạy được.

# 💻 Chuẩn Code

Ví dụ:

```python
def calculate_average(scores: list[float]) -> float:
    """Trả về điểm trung bình; trả 0.0 nếu danh sách rỗng."""
    if not scores:
        return 0.0

    return sum(scores) / len(scores)
```

### Người học được khuyến khích

* ✨ Đặt tên rõ nghĩa.
* 🧩 Giữ hàm có trách nhiệm rõ ràng.
* 🚫 Tránh `bare except:`.
* 📁 Dùng `with` khi làm việc với file.
* 💬 Comment để giải thích **tại sao**, không lặp lại code.
* 🧪 Viết test cho hành vi quan trọng.
* 🏷️ Sử dụng type hints khi chúng giúp code dễ hiểu hơn.
