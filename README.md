Mỗi tuần V2 đi theo learning pattern: README ➔ Notes/Examples ➔ Exercises ➔ Self-check/Tests ➔ Challenge ➔ Mini-project📏 Chuẩn code của khóa họcPythondef calculate_average(scores: list[float]) -> float:
    """Trả về điểm trung bình; trả 0.0 nếu danh sách rỗng."""
    if not scores:
        return 0.0
    return sum(scores) / len(scores)
